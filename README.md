📌 Project Description

A decentralized and permissionless To-Do List application built using Soroban smart contracts on the Stellar blockchain. This project allows users to manage their tasks securely without relying on any central authority.

⚙️ What it does

The smart contract enables users to:

Create tasks

View tasks

Mark tasks as completed

Delete tasks

All operations are handled on-chain, ensuring transparency and immutability.

✨ Features

🔓 Permissionless – Anyone can interact without restrictions

🧾 On-chain storage – Tasks are stored on the blockchain

🔐 Secure – No central control or data manipulation

⚡ Fast & Low Cost – Powered by Stellar’s efficient network

👤 User-specific tasks – Each user manages their own list
